# Site Império

Site institucional estático para o Império, salão de beleza e bronze em São Bernardo do Campo.

## Atualizações desta versão

- Seis cards de serviços agora possuem imagens relacionadas a cada atendimento.
- A seção de depoimentos foi preenchida com três avaliações reais fornecidas pelo cliente.
- O resumo do Google informa nota 5,0 e 67 avaliações, conforme a imagem enviada.
- Um mapa incorporado do Google foi adicionado no início do rodapé.
- O rodapé informa que o site foi desenvolvido por Bruno Vieira Santos.

## Arquivos

- `index.html`: conteúdo, serviços, avaliações, mapa, SEO, Open Graph e links.
- `styles.css`: identidade visual, cards com imagens, avaliações, mapa, responsividade e animações.
- `script.js`: menu móvel, animações com IntersectionObserver e ano automático.
- `assets/logo-imperio.png`: logo usada na identidade visual.
- `RELATORIO-ADAPTACAO.md`: alterações, linhas, placeholders e autoverificação.

## Imagens dos serviços

As fotos dos cards são carregadas por URLs externas do Unsplash. Elas podem ser substituídas por fotos próprias do salão sem alterar a estrutura dos cards.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Publicação

O projeto pode ser publicado no GitHub Pages, Netlify ou em outra hospedagem de arquivos HTML, CSS e JavaScript.

Antes da publicação definitiva, confirme os itens marcados como `[PLACEHOLDER]` e troque a imagem Open Graph por uma URL absoluta do domínio final.
